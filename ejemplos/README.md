# Ejemplos

Pruebas reales de los flujos y lecciones aprendidas, reescritas en genérico: qué pasó, qué regla salió y cómo se comprobó. Los nombres de personas, repos privados y proyectos se quitan; lo que queda es lo que le sirve a otro equipo.
