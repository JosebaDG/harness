# Especialistas

Los gorros que se pone un agente para un trabajo: misión, qué decide y qué no, criterios, material, entregas y límites, con la plantilla común para crear gorros nuevos. Un gorro entra cuando tiene ficha completa.

- [plantilla.md](plantilla.md): la plantilla común. Cada gorro nuevo parte de ella.

Los gorros llegan en este mismo PR de contenido, uno por archivo.
